# Экспертная система: Нобелевские лауреаты по литературе

Лабораторная работа по дисциплине «Базы данных» / «Экспертные системы».

Экспертная система, угадывающая загаданного персонажа — лауреата Нобелевской премии по литературе — с помощью вопросов и байесовского вывода.

---

## О проекте

Система задаёт пользователю вопросы вида «Он/Она из СССР?», «Получил(а) премию до 1950 года?», «Писал(а) преимущественно поэзию?». На основе ответов («Да», «Нет», «Не знаю») пересчитываются вероятности кандидатов по **формуле Байеса**, и система либо угадывает персонажа, либо продолжает задавать вопросы.

**Что реализовано:**

- 20 персонажей — лауреаты Нобелевской премии по литературе.
- 20 вопросов, различающих персонажей по биографии, языку, жанру и истории премии.
- Матрица знаний 20×20 в реляционной БД (SQLite).
- Логика вывода на основе информационного выигрыша (энтропия Шеннона) и приоритетных вопросов.
- Ограничение «Не знаю» — не более 2 раз за игру.
- Добавление новых персонажей и вопросов **прямо через интерфейс**.

## Как играть

1. Запустите `python main.py`.
2. Загадайте любого из 20 лауреатов.
3. Отвечайте на вопросы: **Да**, **Нет** или **Не знаю** (не более 2 раз за игру).
4. Система попытается угадать персонажа.

### Добавление персонажа

**Файл → Добавить персонажа** → введите имя → в открывшемся окне расставьте ответы **Да/Нет** на все вопросы.

- По умолчанию везде «Нет». Удобно: нажмите **«Везде Нет»**, потом поставьте «Да» на 3–5 характерных вопросов.
- Кнопка **«Сохранить»** записывает ответы в матрицу.
- Кнопка **«Отмена»** удаляет недонастроенного персонажа.

### Добавление вопроса

**Файл → Добавить вопрос** → введите текст → для каждого персонажа отметьте **Да/Нет**.

- Логика симметрична добавлению персонажа: заполняется **столбец** матрицы.
- Новый вопрос начнёт задаваться в игре, только если он **различает** персонажей (у кого-то Да, у кого-то Нет).

## Архитектура и алгоритм

### Формула Байеса

Для каждого кандидата `Aₓ` после ответа пользователя на вопрос `B` пересчитывается апостериорная вероятность:

```
P(Aₓ | B) = P(B | Aₓ) · P(Aₓ) / P(B)
```

где:

- `P(Aₓ)` — текущая вероятность кандидата (до вопроса),
- `P(B | Aₓ)` — вероятность, что кандидат `Aₓ` ответил бы так же, как пользователь (1.0 — совпал ответ, 0.0 — не совпал),
- `P(B)` — нормировочная константа, сумма по всем кандидатам.

### Выбор следующего вопроса

Каждый вопрос оценивается по **информационному выигрышу** (разность энтропий до и после):

```
H(X) = −Σ P(Aₓ) · log₂ P(Aₓ)
gain(q) = H_before − H_after(q)
```

Выбирается вопрос с максимальным `gain` — среди тех, что **различают** оставшихся кандидатов.

Отдельно задан список **приоритетных вопросов** (например, «Это женщина?»), которые задаются раньше остальных — они редко различают, но при срабатывании дают огромный отсев.

### Ответ «Не знаю»

- Если пользователь отвечает «Не знаю» — вероятности **не пересчитываются**, вопрос просто исключается из пула.
- Лимит — 2 раза за игру (по требованию задания).
